# Pinned native Stepper accessibility observation

A fresh caller used the unchanged 89-file pinned desktop source. CUA observed
the public control with a Quantity label, static text value, and Remove/Add
buttons. Add then two Remove clicks produced owner values 2/3/2/1; Remove became
disabled at 1. Tab reached the outside field, which accepted Native reader
without another Stepper request. Six original CUA responses and their matching
calls, extracted from the persisted canonical transcript, are retained.

Three initial wrapper launches trapped because its resource bundle was beside
the executable rather than under Contents/Resources. The unchanged bundle was
placed at the generated resource accessor's expected location. The helper
binary and pinned component did not change. Original diagnostics and Apple
source/binaries remain external; hashes and relevant stack metadata are here.
The caller was stopped and its owned Finder window closed. Its output guard
prevents reusing the same caller after closure.

These are bounded accessibility-tree and caller-state observations in this
English native context. VoiceOver speech, native button keyboard activation,
physical input/display, raster and broader locale/state acceptance are pending.
No source reference or acceptance is changed, and no Apple source is included.
