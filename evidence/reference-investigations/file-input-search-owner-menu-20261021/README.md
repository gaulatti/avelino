# Native search owner and token-menu observations

These controlled observations use the pinned desktop Sabella library object,
unchanged from the recorded cached build. Only the two caller helpers were
compiled afresh. The actual runtime is macOS 27.0.1 (26A434), SDK 27.0; the minimum
compilation target macOS 26.0 is a separate fact. Apple helper sources, apps and
objects remain outside this Linux repository. Build commands and input/executable
hashes identify the external producer; this is not independent source replay.

AppKit records two successful callbacks: ordinary browse and raw folder search.
SwiftUI records three: ordinary browse, Everything folder search and Filename
folder search. The last callback normally removes its owner. Every callback
observes public NSOpenPanel.isVisible as true; private importing state, exact
visual ordering and general owner lifecycle equivalence remain unverified.

Filename and Everything tokens expose the same two ordered logical menu choices:
Filename and Everything. Some full CUA text projections duplicate the menu; they
do not establish object identity. The first interrupted Everything Open attempt
is retained in request history and the trace; only the subsequent native Return
attempt is counted as a delivery. Earlier disabled-Open and Forward observations
remain preserved in their original capsules and are not generalized into rules.

The late Everything projections contain two external v24 fixture copies despite
the selected folder radio. This contradicts a general exclusion conclusion from
earlier narrow projections. Query readiness, stable membership, general scope and
history equivalence remain open; the Linux scope policy is not changed to imitate
an unexplained native result.

The four controlled CUA JSON exports preserve serialized text. JPEG base64 in the
saved session log is elided: complete screenshot bytes are unavailable. These
exports are behavioral observations, not raster baselines or complete native AX
attribute archives. The private initial directory listing and executable CUA
action arguments are deliberately absent. Native hierarchy/identity, reader,
physical input/display, independent replay and raster acceptance remain pending.
