# Native date literal input

Fifteen observations of the public pinned Sabella control record CUA pointer and
Up-key actions in an isolated native window. The existing verified Sabella object
is reused, not independently rebuilt. The helper only reads public AppKit state,
caches owned-view images and labels its typed fixture buttons. Swift/Apple helper
source and executables remain external. The library reference is unchanged.

With Hebrew day or month selected, clicking the visible bet literal leaves the
complete root PNG and model byte-identical, sends no owner request, and opens no
calendar. Up then advances the retained day by one day or the captured Hebrew
month by 30 days. English slash input similarly retains month and advances it by
31 days; Arabic slash input retains year and advances it by 365 days. These are
four bounded histories, not general calendar arithmetic acceptance.

An initial Hebrew literal click takes focus from the window into the date picker,
selects its displayed year, and sends no request or calendar opening. Up advances
the native Hebrew year to the captured March29 2025 instant. Thus a literal press
must not be discarded before the native focus path. Initial field selection,
other focus histories, composition, reader output and physical acceptance remain
open; the Linux implementation's initial field selection is not accepted here.

The raw source images use actual backing DPR2 with the SwiftUI helper displayScale
set to1. No image is resized. The four retained-selection comparisons use exact
PNG byte identity. CUA coordinates refer to the1400 by1204 app screenshot; helper
images cover its1280 by800 content canvas. Each selected journal record retains
its actual configuration, native controls, focus, model, owned windows and input
receipt. Fifteen selected records are preserved; full raw journals remain at the
external paths with hashes and record counts in provenance.json. The initial
bare-executable CUA transport failure is retained and excluded from OS-input
claims. The packaged executable is byte-identical to the compiled executable.

cases.json maps these source histories to the corresponding Qt locale, calendar,
selected field and separator ordinal for regression coverage. Candidate-side
caller mirroring, both endpoints and DPR1/2 are further Qt invariant checks, not
additional native observations. Glyph clipping and logical/rendered UTF16 mapping
remain separate, unresolved work. Existing strict raster comparisons and all
reference pins, masks, resizing rules, tolerances and approved exceptions remain
unchanged. No desktop entry gains acceptance.
