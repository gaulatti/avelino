# Retain the selected date field on a literal click

A literal click follows Qt's normal focus/editing path and restores the selected
field on release, but no longer emits calendar activation. Classification uses
the actual field reservation, rather than the cursor offset: an Arabic RTL mark
can map a separator hit to the following year's cursor. Logical text, UTF16
selection, cursor conversion, shaping, clipping and accessibility geometry are
unchanged. Selected components suppress the insertion caret while preserving
input-method cursor geometry. The generic rules have no locale-specific exception.
