# Installed Stepper reader observations

The installed catalog from published commit `899f3e8` was exercised with only
its package prefix and an external observer mounted. No application source or
build tree was mounted or changed. The retained producer is source attempt 8
in the DateRange lifetime capsule; its library and catalog hashes bind these
runs to the same package. No new Qt suite execution is claimed.

Reader 2 uses XCB/software/light at DPR 1. Reader 3 uses nested
Wayland/OpenGL with Mesa llvmpipe, dark appearance, DPR 2 and text scale 1.5.
Each completes 13 operator phases: named-button focus and Orca/Speech Dispatcher
receipts; assistive increment/decrement through the owner; lower/upper bounds
and rejected disabled actions; Space activation in both directions; and focus
followed by keyboard editing in the next text field. Raw accessibility trees,
events, screenshots and complete logs are preserved. Audio goes to the controlled
null device. These are virtual Linux sessions, not physical/native acceptance.

Numeric value feedback is unresolved. Both raw client logs contain Qt's
`ValueChanged event and no ValueInterface or ComboBox` warning. In the bounded
increment/decrement and bound-action speech windows, no `SPEECH OUTPUT` line
announces the changed number. The buttons' names and the accessible static
value update correctly, but those observations do not establish usable numeric
reader feedback. Native keyboard/reader comparison remains pending; no
unmeasured announcement policy is introduced.

Reader 1 remains a failure after six phases: the observer required a fresh named
utterance when the same button was already focused. The corrected observer first
focuses the outside field, verifies that focus, then focuses the target button.
It retains the same assertion deadlines and named speech checks. A JSON newline
serialization correction also precedes the first complete report; the old runner,
observer and negative output are retained. No package changes were needed.

Regular files are retained by content hash, with deterministic gzip for text and
original PNG bytes for images. Runtime Unix sockets are recorded separately
because they are not files. Output copy happens after owned children stop.
The verifier checks original payload hashes, runtime/producer bindings, each
accessible value and enabled/focus state, named speech byte windows, the speech
gap, and all prior protected inventory fields. Negative contracts reject
fabricated owner values, enabled bound buttons, missing focus/speech, wrong
producers, relabelled runtime and acceptance promotion.

Run `python3 scripts/verify-stepper-reader.py` to audit the retained evidence.
This does not launch the package or prove native parity. References, expected
images, fonts, tolerances, masks, exceptions and existing acceptance stay intact.
