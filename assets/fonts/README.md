# Bundled fonts

Sabella ships static Thin through Black faces so Core Text can resolve every
SwiftUI weight without synthesizing a face or falling back to a system font.

- Encode Sans comes from `thundernixon/Encode-Sans` commit
  `6407de854a4dc3bfbe2160a11c5b57f5a1baf3bc`, under
  `fonts/EncodeSans/static`.
- Libre Franklin comes from `googlefonts/Libre-Franklin` commit
  `310b7eef1f7b7ba82322295e0034675ea68040b0`, under `fonts/ttf`.

Each family is distributed under the SIL Open Font License in its adjacent
`OFL-*.txt` file.
